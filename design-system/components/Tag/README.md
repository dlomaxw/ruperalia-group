# Tag
Tags label a business's sector, type, country and relationship to the group.

- Default tags (stone fill, muted text) for sector and country: "Hospitality", "Uganda".
- Relationship tags use the approved words only: Group company, Group brand, Managed property, Joint venture, Affiliate.
- Status colours (`--positive`, `--caution`, `--critical`) are for the CMS; each tag still carries its word.
