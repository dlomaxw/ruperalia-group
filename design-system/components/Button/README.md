# Button
Buttons start an action or lead to a primary destination; use one primary per view.

- **Primary** (`rg-btn rg-btn--primary`): red fill, white text. "Explore our businesses", "Send enquiry".
- **Secondary** (`rg-btn rg-btn--secondary`): ink outline. "About Ruparelia Group".
- **On dark** (`rg-btn rg-btn--on-dark`): for maroon bands.
- Labels are verbs, sentence case, no trailing arrows in copy (the site may add a → glyph).
